# Pragya's Birthday Surprise ❤️

A single-file birthday website for Pragya Sharma.

- Birthday: 4 October
- Countdown target: 12:00 AM IST
- Names: Pragya Sharma + Tanmay Pathak
- Gift remains locked until countdown reaches zero.
- After opening, a romantic newlywed message is revealed.
- No photos are required; a gallery can be added later.

## Run
Open `index.html` in a browser.

## Host
The same file can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting service.
